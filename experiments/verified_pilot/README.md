## 预先确定的设计

- 8 道自建 Python 函数题：带引号分隔记录、百分号路径段、整数比例分配、幂等转账、路径通配符、版本比较、加权分位数、开闭区间并集。
- 每题参考实现须通过隐藏测试，预设单规则变异须失败。8/8 参考和 8/8 变异检查已通过；测试含手算实例、有限穷举、固定种子性质检查。
- 同一份初稿用于 direct、self_1、self_3、verified。self_1 是三轮自检的第一轮结果，不另抽样。
- 自检每轮“提出反馈 → 重写”，最多三轮；verified 独立找最多三个反例、盲审预期、隔离执行，只在观察到失败后修正一次。
- 同一模型/温度/输出长度；每种改进方法每题最多增量 0.30 元保守预算；奇偶题交替先后顺序。相同上限不等于相同实际费用，必须同时报告实耗。
- 隐藏测试和参考实现只用于生成结束后的评测。运行中的反例预期不使用参考实现纠正；事后另统计参考实现是否同意模型生成的预期。
- 单次重复，探索性小样本。题目与测试由本次实现者编写，不是独立第三方基准；不能作显著性或泛化优势结论。

机器可读协议及源码散列见 freeze.json。首次冻结保留为 attempt1_freeze.json，首次源码另打包保存，原始失败账本保留在 verify-runs/pilot/。鉴于没有任何模型输出，后续只补充日志/统计和格式边界处理，没有更改题目或模型提示词。

第一次失败请求保留 0.024428 元预留额。后续整轮上限从 5 元减为 4.975572 元；连同此前实验的高峰价保守账本 4.34970048 元，累计保护总额为 9.34970048 元，不超过原授权的 10 元。

## 离线复核

当前源码包含实验结束后新增的选项。复放旧实验应在仓库根目录使用冻结源码恢复脚本，无需密钥：

```bash
venv/bin/python experiments/verified_pilot/replay_frozen.py
venv/bin/python experiments/verified_pilot/analyze.py
```

复放在临时目录恢复旧源码、核对冻结散列、重建请求与验证决策并重新执行隐藏评分，不修改原始记录。分析脚本只进行离线执行并更新合并统计。

原 `run.py run` 要求新的输出目录，且启动时核对冻结散列；当前源码不满足旧冻结，因此它会拒绝付费运行。新的模型实验须另立协议和源码冻结，不得覆盖本轮材料。summary 的 available / completed_paired_tasks 用于识别有效样本，不能把 unavailable 计成算法答错。费用项 self_1 与 self_3 有重叠，不可重复相加。
